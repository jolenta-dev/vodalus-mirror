#07/04/2026 Vodalus News!

i've been working on vodalus a lot lately. "but the website looks the same??" I hear you asking.

head over to <a href="https://staging.vodalus.org/" target="_blank">staging.vodalus.org</a> to see what i'm cooking up.

for the technically inclined, here's what's happening behind the scenes (check out the <a href="https://gitlab.com/jolenta/vodalus/-/tree/refactor">branch for the refactor</a> to see the code for yourself) is this:

i am accepting how bad vodalus currently is. the main barrier to me working on this has always been how messy it is, so i'm making a real effort to fix that.

starting with frontend, i'm breaking all the elements into their smallest component pieces (i call these primitives) to form larger building blocks of "radicals" that i can then use to dynamically render pages through simple uses of classes.

no more janky CSS rules, no more weird HTML issues, just pure OOP TypeScript from here on out. It's going pretty well so far, but it's huge slog to get done and i have yet to even touch the backend.

so the repo and this site will look dead for a while, but if you pop over to <a href="https://staging.vodalus.org/" target="_blank">staging</a>, you should see my current progress.

someone reading this will say "so you've basically just made a more complicated version of JSX/React/Vue/&c?". sorta, yeah. i'm still opposed to using any large libraries for this site for arcane personal reasons, so i won't use any of those, but it's the right way to build a website in 2026 and i want vodalus to be fun and maintainable for a long time to come.

that's all for now. i'll likely update here every now and then as i make refactor progress.
